How booking works

There is no online ticketing system at the moment. For each announced performance, write to us via the contact form, by e-mail or by phone, stating the number of seats you would like — we will confirm availability.

Would you like online ticket sales?

The page structure allows an external ticketing platform (e.g. iabilet.ro, entertix.ro) to be added at any time — instead of the “Book via contact” button, each event card can link directly to the ticket page of the chosen platform.
